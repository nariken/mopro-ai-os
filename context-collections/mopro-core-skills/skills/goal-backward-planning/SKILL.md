# Goal-backward planning

活動量を増やす前に、目標から必要な変化を逆算する。

## 設計

1. 目標値、期限、対象、現状値を定義する。不明な現状値は仮定として明示する。
2. 最終成果を、観測可能な先行指標へ分解する。
3. 各施策がどの指標を、どの仮説で動かすかを対応付ける。
4. 一人運用の時間、予算、依存関係を制約として計画へ入れる。
5. 最小実験、成功基準、停止または修正条件を決める。

## 優先順位

まず、目標への寄与が大きく、低コストで検証でき、学習が次の施策にも残るものを選ぶ。測定できない大規模施策は、測定可能な小さな実験へ分割する。

## 出力

目標、前提、指標ツリー、優先施策、担当、期限、必要コスト、判定日を一続きで示す。予測値は確定値と区別し、計算根拠を残す。
