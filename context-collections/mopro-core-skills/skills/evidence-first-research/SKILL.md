# Evidence-first research

依頼の判断に必要な情報だけを集める。検索量ではなく、結論の再検証可能性を成果とする。

## 実行原則

1. 最初に判断したい問い、期限、対象範囲を一文で定義する。
2. 既存の正本と一次情報を優先する。更新され得る事実は取得日時を残す。
3. 各重要主張を `確認済み`、`推測`、`未確認` のいずれかに分類する。
4. 数値は単位、期間、母数、計算式を保持する。比較条件が異なる数値を並べない。
5. 情報不足でも埋め合わせて断定しない。結論が変わる不足だけを明示する。

## 出力

- 結論と、その結論で可能になる判断
- 重要な根拠と出典
- 推測および未確認事項
- 次に確認すべき最小の項目

外部サービスへの書込み、問い合わせ、購入、API利用は調査に含めない。必要なら候補として提示し、別途権限を確認する。
